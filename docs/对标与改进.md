## 二、差距量化

### P0-1　未做岁差改正（最严重）

界面语境是北宋（苏颂水运仪象台，约 1052 年），但星位是 J2000 历元。948 年的岁差不是可忽略量。按 IAU 1976 岁差模型把 `chineseSky.json` 全量回推到 1052 年实测：

| 星 | J2000 去极度 | 1052 年去极度 | 位移 |
| --- | --- | --- | --- |
| 勾陈一（今北极星） | 0.736° | 5.916° | 5.38° |
| 北极二 | 15.845° | 12.016° | 3.88° |
| 织女一 | 51.217° | 51.702° | 6.22° |
| 北斗一 | 28.249° | 23.358° | 8.56° |
| 天狼 | 106.713° | 106.161° | 10.15° |
| 河鼓二 | 81.133° | 83.108° | 11.50° |
| 娄宿一 | 69.192° | 74.078° | 13.07° |
| 参宿四 | 82.593° | 83.292° | 12.69° |
| 心宿二 | 116.432° | 113.807° | 13.18° |
| 角宿一 | 101.161° | 96.065° | 13.21° |

**全部 1386 星：平均位移 10.70°，中位 11.96°，最大 13.22°。**

后果是具体的，不是抽象的：

- 天极与勾陈一在画面上几乎重合（0.74°），而北宋时实际相距 **5.9°**——宋人测「北极星离极三度有余」的记录在当前视图里无法成立；
- 内规（恒显圈）半径由「90° − 观测地纬度」定为 55.2°，但恒显区边界随岁差漂移，用 J2000 星位绘北宋的恒显圈，圈内/圈外会错判若干星官；
- 二十八宿与十二次的相对位置整体偏转，无法与《新仪象法要》星图逐星比对。

> 这一条直接决定项目是「好看的星图」还是「可做学术引用的复原件」。敦煌星图把岁差作为卖点，Stellarium 的 skyculture 体系也强制带 `epoch` 概念，说明这是该品类的及格线。

### P0-2　二十八宿天区为近似划分

当前 `scripts/export_sky.mjs` 用 `mansionOfRa(meanRa)`，即**取星官成员平均赤经落到哪个宿的赤经区间**。正统做法（Stellarium `lunar_system.defining_stars` 给出的 28 颗距星 HIP）是以距星定宿界，把天球从北天极切到南天极成 28 个楔形区。

差异后果：位于宿界附近、成员又跨界的星官会被整体错判到邻宿（例如井/鬼、翼/轸一带），而「某星官属某宿」是《步天歌》与分野体系的骨架。修法明确——数据源里已经带 `determinativeStar` 字段，只是没用它切界。

### P1　内容密度

- **无银河**。三维天球与盖图都是空底，只有星点与连线。敦煌星图用真实银道面 + 约 11 万微星，观感差距最大的一项。技术上用银道坐标生成粒子带即可，成本低于净收益。
- **三家星配色缺位**。石氏（朱）/甘氏（墨）/巫咸（黄）是古星图的本体语言，当前用的是四象三垣配色（现代再创作）。建议做成可切换的色彩体系，而不是替换。
- **无月与五星**。环系画了白道环，但无月体；无行星。恒星时内核已经具备，补月相与五星是纯增量。
- **恒显圈写死 34.8°N**。已有 `SITE` 常量，但纬度不可调，无法演示「南巡所见星空不同」。

## 三、建议的执行顺序

1. **岁差 + 历元选择器**（P0-1）。在 `astro.ts` 加 `precess(ra, dec, fromEpoch, toEpoch)`（IAU 1976 三转角已验算），数据管线增加 `--epoch` 参数，界面加「历元：1052 北宋 / J2000 / 今日」三档。这是唯一会改变现有画面观感的改动，其余都是增量。
2. **距星切宿**（P0-2）。`export_sky.mjs` 已有 `determinativeStar`，改为按距星赤经排序切 28 个扇区，重跑数据管线，`mansionCount` 不变但归属变准。
3. **银河层**（P1）。银道坐标 → 粒子带，挂到 `skyGroup` 内随天球一起转。
4. 三家星配色切换 → 月与五星 → Canvas 化 → 测试与 CI → 分享链接与导出。

第 1、2 条属于「学术正确性」，成本集中在数据管线与一个工具函数，改动面可控；第 3 条是观感收益最高的一项。
