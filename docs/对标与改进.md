## 二、已完成

### ✅ P0-1　岁差改正 + 历元选择

`src/lib/astro.ts` 实现 IAU 1976 三转角（Meeus 21.2），`src/lib/epoch.ts` 在显示时按历元重算整表。三档历元：北宋 1052（默认）/ J2000 / 当代。1582 年前按儒略历计历。

实测（`npm run test:astro` 已断言）：

| 星 | J2000 去极度 | 1052 年 | 位移 |
| --- | --- | --- | --- |
| 勾陈一 | 0.736° | **5.916°** | 5.38° |
| 角宿一 | 101.161° | 96.065° | 13.21° |
| 心宿二 | 116.432° | 113.807° | 13.18° |
| 娄宿一 | 69.192° | 74.078° | 13.07° |

全表 1386 星平均位移 **10.70°**，中位 11.96°，最大 13.22°。

拱极星的判据（去极度 ≤ 纬度）因此也自动正确：北宋的恒显圈与今天不同，现在图上是按北宋算的。

### ✅ P1　银河

`src/lib/milkyway.ts` 由银心（α=266.4051°, δ=−28.9362°）与银河北极（α=192.8595°, δ=+27.1283°）构造正交基，把银道坐标变换到赤道坐标；银纬 σ≈7° 正态收拢，银心加权，|b|<2.5° 压暗模拟暗尘带。

- 三维：9000 点自定义着色器，随岁差与天球自转
- 盖图：2200 点合成单条 `<path>` + `feGaussianBlur` 形成雾带，按内外规拆两层各自跟随圆盘旋转
- 随机数用固定 seed 的 mulberry32，保证 SSR/hydration 一致

变换精度自检：银心、银北极两点反算精确命中，误差 < 1e-4°。

## 三、纠正一处误判

**上一版报告称「二十八宿按星官平均赤经归宿，非距星切界」——这是错的。** 核对 `scripts/export_sky.mjs` 后确认：`mansionsRaw` 已取 `lunar_system.defining_stars` 的 28 颗距星，`boundaries` 用距星赤经排序切扇区，`buildMansionLines()` 也以距星赤经画经线。此项目从一开始就是距星切界，无需改动。

（`mansionOfRa()` 里的 meanRa 只用来判断「某星官归入哪个宿」，判据本身仍是距星划定的区间，不是宿的平均赤经。）
