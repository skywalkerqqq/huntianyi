## 性能修复：切换提速 + 盖图缩放（同日第六轮）
- 用户反馈「切换好慢 / 盖天图不能放大缩小」。
- 慢的根因①：dev 模式实时编译路由（切换实测 1.8-2.0s）→ 生产构建后 249ms/124ms（~10×）。
- 慢的根因②（组件层）：SkyMap 1386 颗星每颗都绑独立 onMouseMove/onClick，hover 每帧全量重渲染 → 重构为**事件委托**（data-si + svg 顶层 handler）+ **memo 化 StarLayer/LineLayer**，hover 只更新 tooltip。
- 盖图缩放/平移：动态 viewBox（getScreenCTM().inverse() 做坐标转换，自动适配缩放）；滚轮（passive:false 手动绑定）、双指捏合、Alt/中键拖动平移、双击复位、右下 zoombar（+/−/复位/百分比）、dock 缩放滑杆（log2 刻度）。缩放范围 0.5×–12×。
- 亮星标注字号按 1/(VIEW/vb.w) 反向缩放 → 放大时屏幕字号恒定。
- **环境坑（重要）**：`next build` 被 SAFE_DELETE_BULK_CONFIRM_REQUIRED 拦截（Next 内部清理 distDir/export 触发批量删除保护，与沙箱无关，是注入 Node 的 shim）。解法：`CODEBUDDY_SAFE_DELETE_ENABLED=0 NEXT_DIST_DIR=<全新目录> npm run build`。distDir 默认已设为 build-p3；重建时需换新目录名。
- 生产构建：/ 与 /flat 均为完全静态预渲染（○ Static），首字节 ~0.2s。

## 天象同步：真实恒星时驱动星空（同日第八轮）
- 需求「跟显示星象同步 / 可通过时间矫正 / 可关闭」→ 星空按开封真实恒星时自转 + 任意时刻校正 + 开关。
- 新文件：`src/lib/astro.ts`（GMST/LST IAU1982、太阳低精度视位置、datetime-local 互转、rotationFromLast=270−LAST）+ `src/components/TimeSync.tsx`（useSkyClock hook + SkyClockPanel）。
- 关键结论（已推演+实测一致）：极坐标星图与三维天球共用同一旋转角 **rotation = 270° − LAST**；三维用 `skyGroup.rotation.y = −(90+LAST)·π/180`（天球组局部+Y=极轴，旋转后 α=LAST 的天体落子午环）。恒星日 86164.0905s（比太阳时快 1.0027×，+1 时钟小时→旋转 −15.041° 而非 −15°）。
- 盖图新增（sync 开启时）：此刻地平线遮罩（`cot p = −cot φ·cos(ψ−270°)`，evenodd 填地平以下区域）+ 子午线 + 天顶标记 + 太阳实时位置；拖动星图=拨动时刻（Δrotation→Δtime 反推）。
- 3D：子午环原本落在卯酉面（XY），已改 `rotation.y=90°` 到 YZ（北天极向 −Z）。太阳做成发光球体挂在 skyGroup 内。
- 校验 scripts/test_astro.mjs：GMST 对照 J2000 与 Meeus 例 12.a 误差 3e-7°；太阳二分二至 α 误差<0.22°；夏至 δ=23.4351°。
- 校验 scripts/verify_sync.cjs（端到端）：旋转角=270−LAST 偏差 0.003°；把时刻校到织女一上中天→该星 Δx=0.05px、Δy=91.8px 落在子午线顶端；+1时=−15.041°；拖动拨时刻；关闭不跳变；3D 开同步后画面确实变化；console 零报错。
